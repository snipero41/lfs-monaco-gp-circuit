# Monaco GP Circuit (LFS)

Monte Carlo street circuit, converted from Assetto Corsa to Live for Speed with lfs-track-builder.

## Credits

- Original Assetto Corsa track: **Vinicius Preu**
- LFS conversion: shared with the original author's permission

## Install

Through LFS's **Get mods** screen: add this repository to `mods\repositories.txt` in your LFS folder:

```
snipero41/lfs-monaco-gp-circuit
```

Then restart LFS and install "Monaco GP Circuit" from Get mods.

Requires lfs-custom-track's dsound.dll and a stock LFS.exe.
